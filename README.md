# 🔱 مملكة سولاريا — Kingdom of Solaria

موقع مملكة افتراضية باللغة العربية، بتصميم أسود وذهبي، قابل للنشر مجانًا على GitHub Pages. **هذه ليست دولة معترفًا بها، وجوازاتها وأموالها رمزية لا تستخدم بوصفها وثائق قانونية أو أدوات مالية.**

## الواجهة الحالية
- صفحة رئيسية، الوزارات، ميثاق المملكة، المحافظات الافتراضية، الخدمات والفعاليات المستقبلية.
- تسجيل وإنشاء حساب بالبريد وكلمة المرور عند ربط Supabase.
- طلب الجنسية الافتراضية وتتبع حالته، وبطاقة رمزية قابلة للطباعة بعد الموافقة.
- لوحة تحكم للملك والوزراء: قبول/رفض الطلبات ومراجعة طلبات الخدمات.
- إصدار المراسيم: **للملك فقط**؛ سياسة قاعدة البيانات تمنع الوزراء والمواطنين.
- إحصائية إجمالية للمواطنين بدون كشف بيانات المواطنين.
- معالجة آمنة للنصوص المعروضة وتحديد طول المدخلات.

## نشر الموقع من GitHub
1. افتح **Settings → Pages** داخل هذا المستودع.
2. من **Build and deployment → Source** اختر **Deploy from a branch**.
3. اختر **main** و **/(root)** ثم Save.
4. انتظر اكتمال النشر وافتح: https://haidersabba14.github.io/Kingdom-of-Solaria/

## تفعيل التسجيل الحقيقي (مطلوب)
الموقع يبقى واجهة عامة إلى أن تربطه بمشروع Supabase نشط. GitHub Pages لا يوفر قاعدة بيانات أو حسابات بنفسه.

1. افتح https://supabase.com/dashboard وأنشئ أو أعد تفعيل **مشروعًا نشطًا** على الخطة المجانية إن كانت متاحة.
2. من SQL Editor نفّذ الملف `supabase/schema.sql` **مرة واحدة** على قاعدة جديدة (يتضمن سياسات الحماية).
3. من Project Settings / API Keys انسخ **Project URL** و **publishable key** فقط.
4. افتح `index.html` في GitHub، وابحث عن:
   - `YOUR_SUPABASE_URL`
   - `YOUR_PUBLISHABLE_KEY`
   واستبدلهما بالقيم المنشورة، ثم Commit. **لا تضع service_role أو secret API key داخل HTML أو مستودع عام.**
5. من Authentication / URL Configuration أضف موقع GitHub Pages إلى Allowed Redirect URLs و Site URL حسب إعدادات البريد.
6. أنشئ حسابك من الموقع وثبت البريد الإلكتروني إذا تطلب ذلك.
7. من SQL Editor نفّذ هذا الأمر مع **بريدك الحقيقي** لتعيين الملك:
   ```sql
   update public.profiles set role='king'
   where user_id = (select id from auth.users where email = 'YOUR_EMAIL@example.com');
   ```
8. سجّل خروجًا ثم دخولًا ليظهر زر **👑 القصر**. لا يتم اختيار الملك تلقائيًا بناء على بريد أو اسم من الواجهة.

## ملاحظات الأمان
- صلاحيات الملك والوزراء مخزنة في قاعدة البيانات ومحكومة بـ Row Level Security، وليست مجرد أزرار مخفية.
- المواطن يرى طلباته فقط. المراسيم منشورة للجميع. إحصائية إجمالية لا تكشف أسماء المواطنين.
- جوازات سولاريا رمزية فقط. لا تطلب بيانات هوية رسمية أو عناوين أو وثائق.
- للإنتاج العام: راجع سياسات حماية البيانات، فعّل منع الإساءة/الطلبات الكثيفة وحماية البريد، واختبر صلاحيات الحسابات قبل استقبال المستخدمين.
- خدمات Supabase المجانية لها حدود وقد تدخل المشاريع غير النشطة وضع الإيقاف.

## المميزات المقبلة
نظام الأوسمة والرتب، خزينة نقاط SLR غير قابلة للاستبدال بأموال، انتخابات افتراضية مع منع التصويت المكرر، فعاليات ملكية، إدارة محافظات، مجلة سولاريا، إشعارات، وتصدير بيانات المواطن.
